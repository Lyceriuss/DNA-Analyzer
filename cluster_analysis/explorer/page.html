Every tab reads the selected person's genome through public research sources: Clusters (with Nutrition), Medicines, Biomarkers and Gene pathway. Home explains how.

What this tab shows

A lab test reads the body through a number and a reference range that says what is usual. XY's genes sit behind many of those numbers. This tab sets the common lab tests beside XY's genome, so a result can be read knowing where XY's genes would put it and which of XY's variants can move it.

The lab report

The tests in panels, as a lab reports them: heart and vessels, metabolism, liver and kidneys, blood, hormones, and the nutrients' blood tests. Each analyte carries its LOINC code, the code labs order and report it under, and the sample it is taken from.

XY's genetic baseline

Where XY's variants put each value among Europeans, scored from the variants large studies tie to it (PGS Catalog, GWAS Catalog). It is where XY's genes start the value from, not a measurement: the measured value also follows diet, weight, medicines and illness.

Genes that move the reading

Some genes shift the number without changing the body, such as a red blood cell gene that moves HbA1c but not blood sugar: when XY carries one, XY's normal may sit outside the usual range. Others move the level for real, and those are worth following up.

The clinical path

Select a test for why it is ordered, how to prepare and what the result means (MedlinePlus, US National Library of Medicine), then XY's baseline, the variants behind it and where they act (Reactome, Ensembl VEP, GTEx, UniProt). Every finding carries an evidence grade from A+ to C.
